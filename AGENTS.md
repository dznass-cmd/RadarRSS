# OpenCode - Codigo de Autonomia Absoluta

## Regras de Disciplina
- Mantenha um arquivo `todos.md` na raiz como plano mestre e atualize-o a cada passo.
- Atualize obrigatoriamente o `CHANGELOG.md` a cada alteracao funcional.
- Siga rigorosamente o padrao Conventional Commits (feat:, fix:, chore:, docs:).
- NUNCA utilize diretorios RAMDisk (evite variaveis TMP/TEMP apontando para eles).
- Prefira sempre solucoes nativas do WSL2 em vez de binarios Windows para maior estabilidade.

## Ferramentas Disponiveis
- Use `context7` para buscar documentacao atualizada de bibliotecas e frameworks.
- Use `gh_grep` para encontrar exemplos de codigo no GitHub.
- Conecte-se automaticamente aos MCPs disponiveis (Supabase para BD, Exa para buscas, Shadcn para UI) quando configurados.

## Autonomia
- Voce tem permissao total (allow) para bash, edit, read, write, webfetch, websearch, task, question.
- Nao hesite em executar comandos. Prefira agir a perguntar.
- Se encontrar um erro, tente diagnosticar e corrigir antes de reportar.
