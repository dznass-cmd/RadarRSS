# RadarRSS - Diretrizes do Projeto

## Estrutura

- `src/` — codigo Python organizado por modulo
- `scripts/` — scripts PowerShell/Batch do Windows
- `docs/screenshots/` — screenshots de referencia
- `config/` — arquivos de configuracao

## Regras

- Mantenha `todos.md` atualizado como plano mestre.
- Atualize `CHANGELOG.md` a cada alteracao funcional.
- Siga Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`).
- Nao duplique codigo — use os modulos em `src/`.
- Evite hardcodar caminhos especificos de maquina.

## Autonomia

- Voce tem permissao para bash, edit, read, write, webfetch, websearch.
- Prefira agir a perguntar.
- Se encontrar um erro, diagnostique e corrija antes de reportar.
