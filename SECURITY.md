# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within **Radar RSS**, please do **NOT** open a public issue.

Instead, please report it responsibly by:
1. Opening a **Private Security Advisory** on GitHub via [Security Advisories](https://github.com/dznass-cmd/RadarRSS/security/advisories/new).
2. Providing a clear summary of the issue, severity, reproduction steps, and potential impact.

We will review the vulnerability promptly, acknowledge receipt, and coordinate a fix and release.
